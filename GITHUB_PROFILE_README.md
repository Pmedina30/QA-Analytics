## 📂 Featured Projects

### 🔹 [QA Analytics & Data Quality Dashboard](https://github.com/Pmedina30/qa-analytics-dashboard)
> **End-to-end QA analytics pipeline processing 50,100 evaluations**

A complete Data Analytics project simulating a real-world Quality Assurance environment in a contact center. Demonstrates the full data lifecycle from raw CSV to executive dashboard.

**What it does:**
- 🔍 **Data Quality Analysis** — 14 automated validations with a composite DQ Score
- 🧹 **Data Cleaning Pipeline** — 6-step reproducible transformation (never modifies source data)
- 📊 **KPI Framework** — QA Score, Pass Rate, Critical Error Rate, CSAT vs targets
- 👥 **Team & Agent Analytics** — Rankings, top/bottom 10, eligibility-aware analysis
- 📈 **Trend Analysis** — Monthly MoM changes, deterioration detection
- 🔗 **Correlation Analysis** — Pearson r with causal disclaimer
- 💡 **Executive Insights** — Auto-generated Facts / Insights / Recommendations

**Tech used:** `Python` `Pandas` `NumPy` `Matplotlib` `SQLite` `SQL` `Power BI` `DAX` `Excel` `Jupyter`

**Key results from real data:**
| KPI | Result | Target | Status |
|-----|--------|--------|--------|
| QA Score | 89.79% | >= 85% | ✅ |
| Pass Rate | 75.37% | >= 85% | ❌ |
| Critical Error Rate | 2.60% | < 2% | ❌ |
| CSAT | 4.08/5 | >= 4.2 | ❌ |

**Run it yourself:**
```bash
git clone https://github.com/Pmedina30/qa-analytics-dashboard.git
pip install -r requirements.txt
python run_analysis.py
```
